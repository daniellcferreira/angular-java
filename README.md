Este repositório contém o código-fonte de uma aplicação full stack desenvolvida com **Angular** no frontend e **Java (Spring Boot)** no backend. O objetivo é demonstrar a integração entre essas tecnologias para criar uma aplicação web completa, incluindo autenticação, consumo de APIs REST e persistência de dados.

## Tecnologias Utilizadas

### **Frontend (Angular)**
- **Framework:** Angular 14+
- **Linguagem:** TypeScript
- **Gerenciador de Pacotes:** NPM
- **Estilização:** Bootstrap, SCSS
- **Comunicação com Backend:** HttpClient
- **Autenticação:** JWT (JSON Web Token)

### **Backend (Java)**
- **Framework:** Spring Boot 2+
- **Linguagem:** Java 11+
- **ORM:** Hibernate (JPA)
- **Banco de Dados:** PostgreSQL / H2
- **Segurança:** Spring Security + JWT
- **Testes:** JUnit e Mockito
- **Documentação:** Swagger

### **Containerização e Deploy**
- **Docker**: Containeriza a aplicação para facilitar a execução
- **Docker Compose**: Gerencia múltiplos containers (frontend + backend + banco de dados)
- **PostgreSQL**: Banco de dados utilizado para persistência
